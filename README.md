# Snowball Portfolio Lab

검증 가능한 동적 포트폴리오 백테스트 엔진입니다. 계산 엔진, 데이터 공급원, 화면을 분리하여 Streamlit 없이도 같은 전략을 재현하고 테스트할 수 있습니다.

## 현재 범위

- 미국 ETF 연구 프리셋 1·2와 결합 프리셋 3
- 같은 신호를 국내 상장 ETF로 다음 한국 거래일에 실행하는 프리셋 4·5·6
- 프리셋 2의 공격 모멘텀을 1-3-6-9-12개월 단순으로 바꾼 프리셋 7과 프리셋 1·7 결합형 프리셋 8
- MDD 탐색에서 선택한 1-3-6-9-12개월 단순·배당 기준 1.9%의 프리셋 9와 프리셋 1·9 결합형 프리셋 10
- 상대·절대 모멘텀과 방어 스위치
- 카나리아 위험회피
- 10년-2년·10년-3개월 금리차 및 S&P500 배당수익률 신호
- 수정종가·수정시가 기반 리밸런싱
- 거래비용, 적립식 투자, 리밸런싱 기록과 원시 신호
- CLI, Streamlit 화면 및 자동 테스트

Streamlit 화면은 두 연구 전략과 결합 전략을 미국 실행형(1·2·3) 및 국내 실행형(4·5·6)으로 제공합니다. 국내 실행형은 미국 ETF 수정주가로 신호를 계산하고 선택된 종목만 국내 ETF로 치환합니다.

## 설치 및 테스트

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python -m snowball.cli list-presets
streamlit run streamlit_app.py
```

## NiceGUI 개편판

Streamlit 운영판과 나란히 실행할 수 있으며 계산 엔진과 Google Sheet 원장을
공유합니다.

```bash
python nicegui_app.py
```

기본 주소는 `http://localhost:8080`입니다. 로컬에서는 기존
`.streamlit/secrets.toml`을 재사용하고, 배포 환경에서는 아래 환경변수를
설정합니다.

- `GOOGLE_SHEET_ID`
- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `NICEGUI_STORAGE_SECRET` (배포 시 임의의 긴 문자열)

현재 1단계에서는 메인 메뉴와 `계좌_` 탭 목록을 지원합니다. 계좌 성과
대시보드와 백테스트 화면을 순서대로 이전합니다.

Streamlit Cloud의 메인 파일 경로는 `streamlit_app.py`입니다.
배포 의존성은 `requirements.txt`에 명시되어 있으며, `pyproject.toml`은
Poetry가 감지되더라도 애플리케이션 자체를 별도 패키지로 설치하지 않도록 설정되어 있습니다.

화면에서 투자·방어 자산과 모멘텀·위험 회피 조건을 조정한 뒤 제목을
입력하면 `내 프리셋`으로 즉시 저장할 수 있습니다. 사용자 프리셋에는
국내 실행 여부를 포함한 전략 조건 전체가 보관됩니다. Streamlit 재배포나
다른 기기에서도 복원하려면 `내 프리셋 전체 JSON 다운로드`로 백업하고
`프리셋 JSON 불러오기`에서 다시 불러오세요.

## 월간 리밸런싱 메일

GitHub Actions의 `Monthly rebalance email` 작업은 매 미국 거래일
장 마감 후에 실행됩니다. 다음 NYSE 거래일이 새로운 달의 첫
거래일일 때만, 방금 확정된 종가로 목표 종목과 비중을 계산해
메일을 발송합니다. 다음 거래일 시가 매수를 위한 신호이며,
알 수 없는 시가 자체를 예측하지는 않습니다. 메일에는 미국 ETF 목표와
현재의 국내 ETF 대체 제안이 함께 표시됩니다.

기본 발송 포트폴리오는 `config/mailing.json`의 프리셋 3(1+2,
50:50)입니다. 2026-11-02 시가를 모델 운용 시작점으로 하여 다음
메일부터 누적 수익률, 월간 수익률, 현재 낙폭과 운용 중 MDD를 함께
표시합니다. 목록을 수정하면 여러 프리셋을 한 메일에 포함할 수 있습니다.

GitHub 저장소의 `Settings > Secrets and variables > Actions`에 다음
Repository secrets를 추가합니다.

- `SMTP_USERNAME`: Gmail 발신 계정
- `SMTP_APP_PASSWORD`: Google 2단계 인증 후 발급한 앱 비밀번호
- `MAIL_TO`: 수신 이메일. 여러 명은 쉼표로 구분

발송 전 수동 계산 테스트:

```bash
python -m snowball.cli mail-rebalance --config config/mailing.json --date 2026-10-30 --force --dry-run
```

GitHub Actions 화면의 `Run workflow`에서도 `dry_run` 테스트 후
실제 메일을 발송할 수 있습니다.

## 실제 거래 Google Sheet 연결

Streamlit의 `투자 계좌 현황` 화면은 비공개 Google Sheet를 실제 거래
원장으로 사용합니다. 이름이 `계좌_`로 시작하는 탭만 계좌 목록에 표시하며,
각 계좌 탭에 해당 계좌의 거래만 저장합니다. 계좌 탭이 없으면
`계좌_기본계좌`를 만들고 기존 `거래내역`의 기록을 한 번 복사합니다.
`리밸런싱기록`, `월간성과`, `설정`은 공통 시스템 탭으로 유지합니다.
예상 헤더와 다른 기존 계좌 탭은 데이터를 덮어쓰지 않고 연결을 중단합니다.
Google Sheets API 호출을 줄이기 위해 계좌 목록은 5분, 거래내역은 1분 동안
Streamlit 메모리에 캐시합니다. 앱에서 저장·수정·삭제하면 거래 캐시를 즉시
비우며, Sheet를 직접 편집한 경우 화면의 `Google Sheet 새로고침` 버튼으로
계좌 목록과 거래내역을 바로 다시 읽을 수 있습니다.

계좌 화면은 조회 전용 투자 대시보드입니다. 거래 추가·수정은 해당
`계좌_` 탭에서 직접 진행합니다. 수동 입력 행은 `상태`가 비어 있거나
`정상`이면 계산에 포함되고 `취소`이면 제외됩니다. 매수·매도의 `금액`을
비워두면 `수량 × 체결단가`로 계산합니다. 조회 기본기간은 최초 거래일부터
오늘까지이며 기간수익률과 MDD는 입출금을 제거한 시간가중수익률 기준입니다.

1. Google Cloud에서 Google Sheets API를 사용 설정합니다.
2. 서비스 계정을 만들고 JSON 키를 발급합니다.
3. 대상 Google Sheet를 서비스 계정의 `client_email`에 편집자로 공유합니다.
4. Streamlit Cloud의 `Settings > Secrets`에 다음 두 값을 입력합니다.

```toml
GOOGLE_SHEET_ID = "Google Sheet URL의 /d/와 /edit 사이 값"
GOOGLE_SERVICE_ACCOUNT_JSON = '''JSON 키 파일 전체 내용'''
```

인증 JSON 파일과 실제 `secrets.toml`은 저장소에 커밋하지 않습니다.

## 설계 원칙

1. 전략 설정은 `snowball/presets.py` 한 곳에서 관리합니다.
2. 프리셋은 실행 전에 완전성을 검증하므로 누락 키가 런타임 `KeyError`로 이어지지 않습니다.
3. 네트워크 데이터는 계산 엔진 밖에서 주입합니다.
4. 판단에는 반올림하지 않은 원시값을 사용합니다.
5. 자동 테스트와 실제 앱 테스트를 구분합니다.

## 시장 데이터 정책

- 미국 장단기 금리차는 공식 FRED CSV를 사용합니다.
- S&P500 배당수익률 확정치는 번들된 Multpl 월별 스냅샷을 사용합니다.
- Multpl 추정 월은 SPY의 최근 365일 실제 분배수익률에 직전 36개월 확정 구간의 S&P500-SPY 중앙 차이를 더해 보정합니다.
- SPY 보정 자료도 별도 고정 스냅샷으로 저장하며, 수집 실패 시 원래 Multpl 추정값으로 안전하게 되돌아갑니다.
- 기본 실행은 저장소의 고정 시장 데이터 스냅샷을 사용해 같은 과거 결과를 재현합니다.
- `최신 데이터` 모드는 공급원 값을 별도 해시 버전으로 저장하며 기존 고정 스냅샷을 덮어쓰지 않습니다.
- 결과의 `데이터 스냅샷` 탭에서 Multpl 원본값, SPY 분배수익률, 보정차와 최종 판정값을 확인하고 CSV로 내려받을 수 있습니다.
- 같은 탭에서 Multpl 최신값과 고정 배당수익률 스냅샷의 변경·신규 월을 비교할 수 있습니다.
- 결과 상단의 비교 진단자료 ZIP에는 월별 수익률, 리밸런싱, 모든 판단 원시값과 일별 낙폭이 포함됩니다.
- Multpl의 추정치는 숨기지 않고 결과 메타데이터에 해당 월을 기록합니다.
- Robert Shiller 자료는 장기 이력 교차검증용이며 실시간 최신값의 주 공급원으로 사용하지 않습니다.
- FRED와 Multpl의 현재 공개 이력은 과거 시점별 빈티지 데이터라고 간주하지 않습니다.
