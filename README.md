# Snowball Portfolio Lab

검증 가능한 동적 포트폴리오 백테스트 엔진입니다. 계산 엔진, 데이터 공급원, 화면을 분리하여 Streamlit 없이도 같은 전략을 재현하고 테스트할 수 있습니다.

## 현재 범위

- 연구 프리셋 2종의 단일 스키마 관리
- 상대·절대 모멘텀과 방어 스위치
- 카나리아 위험회피
- 10년-2년·10년-3개월 금리차 및 S&P500 배당수익률 신호
- 수정종가·수정시가 기반 리밸런싱
- 거래비용, 적립식 투자, 리밸런싱 기록과 원시 신호
- CLI 및 자동 테스트

Streamlit 화면은 계산 엔진의 실사용 검증을 마친 뒤 마지막 단계에서 추가합니다.

## 설치 및 테스트

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python -m snowball.cli list-presets
```

## 설계 원칙

1. 전략 설정은 `snowball/presets.py` 한 곳에서 관리합니다.
2. 프리셋은 실행 전에 완전성을 검증하므로 누락 키가 런타임 `KeyError`로 이어지지 않습니다.
3. 네트워크 데이터는 계산 엔진 밖에서 주입합니다.
4. 판단에는 반올림하지 않은 원시값을 사용합니다.
5. 자동 테스트와 실제 앱 테스트를 구분합니다.
