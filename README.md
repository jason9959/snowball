# Snowball Portfolio Lab

검증 가능한 동적 포트폴리오 백테스트 엔진입니다. 계산 엔진, 데이터 공급원, 화면을 분리하여 Streamlit 없이도 같은 전략을 재현하고 테스트할 수 있습니다.

## 현재 범위

- 미국 ETF 연구 프리셋 1·2와 결합 프리셋 3
- 같은 신호를 국내 상장 ETF로 다음 한국 거래일에 실행하는 프리셋 4·5·6
- 프리셋 2의 공격 모멘텀을 1-3-6-9-12개월 단순으로 바꾼 프리셋 7과 프리셋 1·7 결합형 프리셋 8
- MDD 탐색에서 선택한 1-3-6-9-12개월 단순·배당 기준 1.9%의 프리셋 9와 프리셋 1·9 결합형 프리셋 10
- 상대·절대 모멘텀과 방어 스위치
- 카나리아 위험회피
- 10년-2년·10년-3개월 금리차 및 S&P500 배당수익률 신호
- 수정종가·수정시가 기반 리밸런싱
- 거래비용, 적립식 투자, 리밸런싱 기록과 원시 신호
- CLI, Streamlit 화면 및 자동 테스트

Streamlit 화면은 두 연구 전략과 결합 전략을 미국 실행형(1·2·3) 및 국내 실행형(4·5·6)으로 제공합니다. 국내 실행형은 미국 ETF 수정주가로 신호를 계산하고 선택된 종목만 국내 ETF로 치환합니다.

## 설치 및 테스트

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
python -m snowball.cli list-presets
streamlit run streamlit_app.py
```

Streamlit Cloud의 메인 파일 경로는 `streamlit_app.py`입니다.
배포 의존성은 `requirements.txt`에 명시되어 있으며, `pyproject.toml`은
Poetry가 감지되더라도 애플리케이션 자체를 별도 패키지로 설치하지 않도록 설정되어 있습니다.

화면에서 투자·방어 자산과 모멘텀·위험 회피 조건을 조정한 뒤 제목을
입력하면 `내 프리셋`으로 즉시 저장할 수 있습니다. 사용자 프리셋에는
국내 실행 여부를 포함한 전략 조건 전체가 보관됩니다. Streamlit 재배포나
다른 기기에서도 복원하려면 `내 프리셋 전체 JSON 다운로드`로 백업하고
`프리셋 JSON 불러오기`에서 다시 불러오세요.

## 설계 원칙

1. 전략 설정은 `snowball/presets.py` 한 곳에서 관리합니다.
2. 프리셋은 실행 전에 완전성을 검증하므로 누락 키가 런타임 `KeyError`로 이어지지 않습니다.
3. 네트워크 데이터는 계산 엔진 밖에서 주입합니다.
4. 판단에는 반올림하지 않은 원시값을 사용합니다.
5. 자동 테스트와 실제 앱 테스트를 구분합니다.

## 시장 데이터 정책

- 미국 장단기 금리차는 공식 FRED CSV를 사용합니다.
- S&P500 배당수익률 확정치는 번들된 Multpl 월별 스냅샷을 사용합니다.
- Multpl 추정 월은 SPY의 최근 365일 실제 분배수익률에 직전 36개월 확정 구간의 S&P500-SPY 중앙 차이를 더해 보정합니다.
- SPY 보정 자료도 별도 고정 스냅샷으로 저장하며, 수집 실패 시 원래 Multpl 추정값으로 안전하게 되돌아갑니다.
- 기본 실행은 저장소의 고정 시장 데이터 스냅샷을 사용해 같은 과거 결과를 재현합니다.
- `최신 데이터` 모드는 공급원 값을 별도 해시 버전으로 저장하며 기존 고정 스냅샷을 덮어쓰지 않습니다.
- 결과의 `데이터 스냅샷` 탭에서 Multpl 원본값, SPY 분배수익률, 보정차와 최종 판정값을 확인하고 CSV로 내려받을 수 있습니다.
- 같은 탭에서 Multpl 최신값과 고정 배당수익률 스냅샷의 변경·신규 월을 비교할 수 있습니다.
- 결과 상단의 비교 진단자료 ZIP에는 월별 수익률, 리밸런싱, 모든 판단 원시값과 일별 낙폭이 포함됩니다.
- Multpl의 추정치는 숨기지 않고 결과 메타데이터에 해당 월을 기록합니다.
- Robert Shiller 자료는 장기 이력 교차검증용이며 실시간 최신값의 주 공급원으로 사용하지 않습니다.
- FRED와 Multpl의 현재 공개 이력은 과거 시점별 빈티지 데이터라고 간주하지 않습니다.
